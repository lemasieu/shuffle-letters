# Shuffle Letters

A simple, interactive web tool that shuffles the letters of any word you enter and lets you copy a random line from the results.

## 🚀 Live Demo

Check out the live demo: [https://www.xn--msiu-goa8b.vn/github/shuffle-letters](https://www.xn--msiu-goa8b.vn/github/shuffle-letters)

## ✨ Features

- **Shuffle Letters** – Enter any word or phrase and shuffle its letters with a single click
- **Random Line Copy** – Copy a randomly selected line from the shuffled output
- **Clean Interface** – Minimal, user‑friendly design with a dark color scheme
- **Responsive** – Works on both desktop and mobile devices

## 🔧 Installation & Usage

1. **Clone the repository**
   ```bash
   git clone https://github.com/lemasieu/shuffle-letters.git
   ```
2. **Navigate to the project folder**
   ```bash
   cd shuffle-letters
   ```
3. **Open the application**

- Simply open `index.html` in your web browser
- Or use a local development server (e.g., Live Server in VS Code)

## 📝 How It Works

1. **Enter a word** – Type any word or phrase into the input field
2. **Click "Trộn" (Shuffle)** – The letters are randomly rearranged
3. **View the result** – The shuffled output appears in the text area below
4. **Copy a random line** – Click the "Sao chép dòng ngẫu nhiên" (Copy Random Line) button to copy one randomly chosen line from the output
